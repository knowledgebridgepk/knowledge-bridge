# Knowledge Bridge

Website for Knowledge Bridge, a worker welfare admission, self-education and referral platform.

## Files
- `index.html` main page
- `assets/style.css` all styling
- `assets/script.js` WhatsApp form and social links
- `assets/favicon.svg` site icon
- `404.html` error page
- `robots.txt` and `sitemap.xml` for SEO

## Publish on GitHub Pages
1. Create a new repository named `knowledge-bridge` on github.com.
2. Upload all files from this folder (keep the `assets` folder).
3. Go to **Settings > Pages**, set Source to **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
4. After a minute your site is live at `https://YOUR-USERNAME.github.io/knowledge-bridge/`.

## After it is live
- Replace `YOUR-USERNAME` with your GitHub username in `index.html`, `robots.txt` and `sitemap.xml`.
- Add your social media links in `assets/script.js` (the `SOCIAL` list).
- Submit `sitemap.xml` in Google Search Console.
